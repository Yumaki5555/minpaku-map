初めての方へ

このマップの目的と使い方、言葉の意味、データを見るときの注意です。

このマップは、身近な地域にある民泊・旅館などの宿泊施設の数を「見える化」することを目的に、各自治体が公表している一覧（PDF・エクセル・CSV）を自動で集めて地図にしたものです。

使い方

  1. 1地域をえらぶ「地域」のボタンで都道府県を切り替えるか、住所・市区町村名を入れて「この場所を表示」を押します。
  2. 2種類をえらぶ民泊・特区民泊・旅館・ホテル・簡易宿所のチェックで、見たい種類だけにしぼれます。
  3. 3点を押す地図の点を押すと、施設の名前・住所・種類・出典が出ます。
  4. 4数を比べる・増減を見るグラフやランキングで市区町村を比べたり、前の資料からの増減を見たりできます。
  5. 5画像で保存地図・グラフ・ランキングは、X（旧Twitter）に投稿しやすい横長の画像（1920×1080）で保存できます。

施設の種類

民泊（住宅宿泊事業）

ふつうの住宅（一戸建てやマンションの部屋など）に、料金を受け取って人を泊める仕組みです。自治体への「届出」が必要で、営業できるのは1年に180日までです。

特区民泊

国が指定した「国家戦略特区」の一部の地域で、自治体の「認定」を受けた民泊です。このマップでは大田区と大阪府内の一部の市が対象です。2泊3日以上の滞在が条件です。

旅館・ホテル

旅館業法の「許可」を受けた旅館やホテルです。

簡易宿所

旅館業法の許可を受けた宿のうち、ゲストハウスやカプセルホテルのように、客室を複数の人で使う形の宿です。

「旅館業」は、旅館・ホテルと簡易宿所をあわせた呼び方です。同じような施設でも、自治体によって「旅館・ホテル」「簡易宿所」などの区分が違うことがあります。

データを見るときの注意

  • すべての施設が載っているわけではありません。公表している範囲は自治体ごとに違います。
  • 「掲載なし」は、施設が存在しないという証明ではありません。一覧に載っていない施設や、一覧を公開していない自治体もあります。
  • 「掲載あり」は、いま営業中であることを保証するものではありません。廃業していても一覧に残っている場合があります。
  • 施設の位置は住所から推定しています。実際の場所と異なる場合があります。中が白い点は、番地まで分からず町の中心付近に置いたものです。
  • 自動で読み取っているため、内容や位置に誤りがあることがあります。正確な情報は、各自治体の公表資料（一覧表の「出典」）でご確認ください。

お知らせ：地図の点の表示を変えました（2026年10月26日）

  • すべての施設を、小さな点で1つずつ表示しています。近くの施設を数字の円にまとめる「まとめて見る」はやめました。施設の多い地域でも点はまとめずに描くので、重なって見える所は、地図を拡大すると分かれて見えます。
  • まったく同じ位置の施設は、点1つにまとめ、点の大きさで件数を表しています。1件・2〜3件・4〜6件・7〜10件・11件以上の5段階で、件数が多いほど少し大きな点になります。種類の違う施設が同じ位置にあるときは、点を件数の割合で塗り分けています。点を押すと、その地点の施設の一覧が出ます。
  • 番地まで分からず町の中心付近に置いた施設は、真ん中が白い点にしました。（これまでは薄い点線の点でした）
  • 背景の地図を選べるようにしました。標準は点が見やすい淡いグレーの地図（OpenStreetMapのデータをもとに、OpenStreetMap Japanが配信している地図を灰色にしたもの）で、これまでの国土地理院の地図にも切り替えられます。
  • 施設の種類の色を少し変えました。民泊は赤、特区民泊は紫、旅館・ホテルは青、簡易宿所は黄土色です。地図・凡例・グラフ・表で同じ色を使っています。

  • 宮城県・広島県・沖縄県の旅館業は、仙台市・広島市・那覇市の分だけを載せています。宮城県・広島県・沖縄県（県が受け付けている地域）と、呉市・福山市は、旅館業の一覧が見つからないため「データ未取得」としています（2026年10月に確認）。
  • 一覧を公開していない市がほかにもあります。豊橋市（民泊・旅館業）、岡崎市（旅館業）、一宮市（民泊）、姫路市（旅館業）、明石市（民泊・旅館業）、久留米市（旅館業）、北九州市（特区民泊）も「データ未取得」です（2026年10月に確認）。
  • 宮城県（仙台市を除く）の民泊は、届出をした人が公表に同意した施設だけです。宮城県は同意を得た施設だけを公表しているため、実際の数より少なくなっています。
  • 愛知県・静岡県・京都府・神戸市・静岡市・仙台市・福岡県の旅館業は、廃業した施設が残っていることがあります。3月末時点の一覧に、その後の毎月の「新しく許可した施設」を足しています。廃業した施設の一覧は公表されていないため、途中で廃業した施設を除けません。京都府（京都市を除く）は2025年3月末時点の一覧が最新のため、特にその心配があります。
  • 名古屋市・福岡市・一宮市の旅館業は、すべて「旅館・ホテル」として数えています。一覧に旅館・ホテルと簡易宿所の区別が書かれていないためです。
  • 福岡県・静岡県の民泊は、県の一覧が県内全域（福岡市・北九州市・久留米市、静岡市・浜松市を含む）です。県が県内全域の民泊の届出を受け付けているためです。
  • 京都市の旅館業の一覧にある「施設外玄関帳場」は数えていません。いくつかの宿の受付だけを行う場所で、宿そのものではないためです。
  • 沖縄県（那覇市を除く）の民泊は、2026年3月31日時点の一覧が最新です。それより後に届出をした施設は、まだ載っていません。
  • 新しく加えた地域の施設の位置は、今後数回の更新でより細かくなります。いまは国土地理院の住所検索で決めた位置です。Yahoo!の住所検索での確認を、毎週月曜・木曜の自動更新で順に進めています。それまでは、位置が少しずれている点があります。
  • 全地域を足した合計の推移グラフは、表示を止めています。加えた9道府県は今回が初めての記録で、それより前の件数が分からないため、合計がどれだけ増えたか・減ったかを正しく表せないからです（「増減を見る」の全地域の合計と、件数の推移のページの「全体の合計」）。都道府県ごと・自治体ごとの推移グラフは、これまでどおりご覧いただけます。
