地図上の位置の決め方と精度について（現時点での判断）

施設の位置は、公表されている住所から自動で推定しています。住所はまず国土地理院の住所検索で調べ、続けてYahoo!の住所検索でも調べて、次のように使い分けています（2026/10/26時点の件数）。

この使い分けにした理由

  • 2026年10月1日に全住所を両方で調べて比べたところ、国土地理院が「番地まで分かった」と答えた住所でも約900件が200m以上（最大で約13km）ずれていました。山あいや海沿いなどの地番の地域で、町の中心付近を返すことがあるためです。そこで、条件を満たすYahoo!の位置を優先しています。
  • 一方でYahoo!は、「墨田区墨田3丁目」で問い合わせると「墨田区緑3丁目」を返すなど、別の町や別の番地を答えることがあります。そのため、番地の数字と町名の両方が一致したときだけ使っています。
  • 新しく加わった住所も、定期の更新で同じ方法で調べています。この判断は、今後の確認結果によって見直すことがあります。

初めての方へ

このマップの目的と使い方、言葉の意味、データを見るときの注意です。

このマップは、身近な地域にある民泊・旅館などの宿泊施設の数を「見える化」することを目的に、各自治体が公表している一覧（PDF・エクセル・CSV）を自動で集めて地図にしたものです。

使い方

  1. 1地域をえらぶ「地域」のボタンで都府県を切り替えるか、住所・市区町村名を入れて「この場所を表示」を押します。
  2. 2種類をえらぶ民泊・特区民泊・旅館・ホテル・簡易宿所のチェックで、見たい種類だけにしぼれます。
  3. 3点を押す地図の点を押すと、施設の名前・住所・種類・出典が出ます。
  4. 4数を比べる・増減を見るグラフやランキングで市区町村を比べたり、前の資料からの増減を見たりできます。
  5. 5画像で保存地図・グラフ・ランキングは、X（旧Twitter）に投稿しやすい横長の画像（1920×1080）で保存できます。

施設の種類

民泊（住宅宿泊事業）

ふつうの住宅（一戸建てやマンションの部屋など）に、料金を受け取って人を泊める仕組みです。自治体への「届出」が必要で、営業できるのは1年に180日までです。

特区民泊

国が指定した「国家戦略特区」の一部の地域で、自治体の「認定」を受けた民泊です。このマップでは大田区と大阪府内の一部の市が対象です。2泊3日以上の滞在が条件です。

旅館・ホテル

旅館業法の「許可」を受けた旅館やホテルです。

簡易宿所

旅館業法の許可を受けた宿のうち、ゲストハウスやカプセルホテルのように、客室を複数の人で使う形の宿です。

「旅館業」は、旅館・ホテルと簡易宿所をあわせた呼び方です。同じような施設でも、自治体によって「旅館・ホテル」「簡易宿所」などの区分が違うことがあります。

データを見るときの注意

  • すべての施設が載っているわけではありません。公表している範囲は自治体ごとに違います。
  • 「掲載なし」は、施設が存在しないという証明ではありません。一覧に載っていない施設や、一覧を公開していない自治体もあります。
  • 「掲載あり」は、いま営業中であることを保証するものではありません。廃業していても一覧に残っている場合があります。
  • 施設の位置は住所から推定しています。実際の場所と異なる場合があります。薄い点線の点は、番地まで分からず町の中心付近に置いたものです。
  • 自動で読み取っているため、内容や位置に誤りがあることがあります。正確な情報は、各自治体の公表資料（一覧表の「出典」）でご確認ください。

地図上の位置の決め方と精度について（くわしい説明）

各自治体が公表している一覧（PDF・Excel・CSV）をもとに自動で作成しています。地図上の位置は住所から自動で推定したもので、ずれている場合があります。正確な情報は各自治体の公表資料をご確認ください。
